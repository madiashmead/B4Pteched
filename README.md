# B4Pteched – What Does AI Do?

A small, beginner-friendly web page that explains what artificial intelligence does.

## Files

- `index.html` – page content
- `style.css` – styling (supports light and dark mode)
- `script.js` – interactive "What AI can do" cards

## Run it

Open `index.html` in any web browser. No install or build step needed.

## Publish with GitHub Pages

In the repo on GitHub: **Settings → Pages → Source: Deploy from a branch → `main` / root → Save**.
The site will appear at `https://<your-username>.github.io/B4Pteched/`.
